     Plan de Implementación: MeditaDJ v4 - Bot de Música Discord

     Resumen

     Crear un bot de música completo para Discord usando Node.js + 
     discord.js v14.25.1 + Lavalink, con dashboard web y soporte para
     YouTube y Spotify.

     Tecnologías Seleccionadas

     Bot Core

     - discord.js: v14.25.1 (ya instalado)
     - Kazagumo: v2.5.2 (wrapper sobre Shoukaku para gestión de colas)
     - Shoukaku: v4.0.1 (cliente Lavalink de bajo nivel)
     - better-sqlite3: v9.2.2 (base de datos para playlists, configs, 
     estadísticas)

     Dashboard

     - Express.js: v4.18.2 (servidor web)
     - Passport + passport-discord: OAuth2 autenticación con Discord
     - Socket.io: v4.6.1 (actualizaciones en tiempo real)
     - EJS: v3.1.9 (templates del frontend)
     - Alpine.js: (CDN) para reactividad en el frontend

     Utilidades

     - dotenv: v16.3.1 (variables de entorno)
     - axios: v1.6.5 (peticiones HTTP para Spotify)

     Configuración de Base de Datos (SQLite)

     Tabla guilds

     CREATE TABLE guilds (
       guild_id TEXT PRIMARY KEY,
       prefix TEXT DEFAULT '!',
       music_channel_id TEXT,
       dj_role_id TEXT,
       volume INTEGER DEFAULT 50,
       announce_songs BOOLEAN DEFAULT 1,
       created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
       updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
     );

     Tabla playlists

     CREATE TABLE playlists (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       user_id TEXT NOT NULL,
       guild_id TEXT NOT NULL,
       name TEXT NOT NULL,
       tracks TEXT NOT NULL,
       created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
       updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
       UNIQUE(user_id, guild_id, name)
     );

     Tabla stats

     CREATE TABLE stats (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       guild_id TEXT NOT NULL,
       user_id TEXT NOT NULL,
       track_title TEXT NOT NULL,
       track_author TEXT NOT NULL,
       track_uri TEXT,
       played_at DATETIME DEFAULT CURRENT_TIMESTAMP,
       duration INTEGER
     );

     Comandos de Música a Implementar

     Básicos

     - /play <query> - Reproducir canción/playlist (YouTube, Spotify)
     - /pause - Pausar reproducción
     - /resume - Reanudar reproducción
     - /skip - Saltar canción actual
     - /stop - Detener y limpiar cola

     Gestión de Cola

     - /queue - Ver cola de reproducción
     - /nowplaying - Ver canción actual con barra de progreso
     - /remove <posición> - Eliminar canción de la cola

     Avanzados

     - /seek <tiempo> - Ir a posición específica
     - /loop <mode> - Loop: none/track/queue
     - /shuffle - Mezclar cola
     - /volume <0-100> - Ajustar volumen

     Playlists

     - /playlist save <nombre> - Guardar cola actual
     - /playlist load <nombre> - Cargar playlist guardada
     - /playlist delete <nombre> - Eliminar playlist
     - /playlist list - Listar playlists guardadas

     Características del Dashboard

     Páginas

     1. Home - Selector de servidores
     2. Music Control - Control en tiempo real de la música
     3. Playlists - Gestión de playlists guardadas
     4. Statistics - Gráficas y estadísticas de uso
     5. Configuration - Configuración por servidor

     Funcionalidades

     - Autenticación OAuth2 con Discord
     - Control de música en tiempo real (Socket.io)
     - Ver y modificar cola de reproducción
     - Estadísticas: canciones más reproducidas, tiempo de uso
     - Configuración: canal de música, rol DJ, volumen predeterminado
     - Sistema de playlists: crear, editar, eliminar

     Consideraciones Importantes

     Seguridad

     - Nunca commitear .env al repositorio
     - Validar permisos antes de unirse a canales de voz
     - Implementar cooldowns en comandos (3-5 segundos)
     - Verificar MANAGE_GUILD en dashboard
     - Sanitizar todas las entradas de usuario

     Performance

     - Límite de cola: 100 canciones
     - Timeout para colas inactivas: 5 minutos
     - Cache de configuraciones de guild en memoria
     - Limpiar colas cuando bot sale de VC

     Experiencia de Usuario

     - Embeds consistentes con colores
     - Mensajes de error claros y útiles
     - Respuestas efímeras para comandos fallidos
     - Progreso visual en comandos largos
     - Notificaciones cuando cambia la canción

     Notas Técnicas

     Registro de Slash Commands

     - Durante desarrollo: registro por guild (instantáneo)
     - En producción: registro global (1 hora propagación)
     - Variable COMMAND_SCOPE en .env controla esto

     Gestión de Colas

     - Colas en memoria (Map: guildId → MusicQueue)
     - Auto-limpieza cuando bot sale del VC
     - Persistencia opcional en DB (feature futuro)

     Dashboard Real-Time

     - Socket.io rooms por guild: guild:${guildId}
     - Emitir eventos: queueUpdate, trackStart, trackEnd
     - Cliente escucha y actualiza UI automáticamente

     Spotify Integration

     - Plugin LavaSrc en Lavalink maneja Spotify
     - Bot solo necesita detectar URLs de Spotify
     - Lavalink convierte a YouTube para reproducción
     - Metadata viene de Spotify API (mejor calidad)
